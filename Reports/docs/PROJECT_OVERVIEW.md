# Project Overview

## Goal
Mobile-first, bilingual-ready website for an hourly celebration room in Vadlamudi, Guntur. Visitors should view the venue, compare packages, understand the monthly promotion, and send an enquiry through the website or WhatsApp.

## Audience
Parents planning birthdays; young adults planning surprises/private celebrations; visitors from Instagram, WhatsApp, Google Search and Maps.

## Business data
- Joybox Party Room

## Key journeys
1. Landing page → package comparison → enquiry form or WhatsApp.
2. Date/time/duration → server availability check → server-calculated quote.
3. Future online booking: atomic slot hold → Razorpay order → server-side signature/webhook verification → confirmed booking.
4. Admin: manage bookings, inquiries, packages, offers, gallery, FAQs and business settings.

## Visual direction
Warm, celebratory, premium-but-approachable; off-white background, dark ink text, coral accent, lavender/peach surfaces, rounded cards, expressive serif headings. Current hero artwork is a CSS placeholder. Replace it with approved Stitch exports and real venue photos.
